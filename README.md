PS2InfoGB
---------

This is Game Boy emulator port of [InfoGB](https://github.com/jay-kumogata/InfoGB) for PlayStation 2 with USB mass support.

It's continuation based on dlanor's source code of PS2InfoGB rev. 4.

The full changelog can be found [here](https://github.com/karasq/PS2InfoGB/blob/master/bin/Read%20Me!.txt).
